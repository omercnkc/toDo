# Product Context

## Neden var
Ekiplerin/kişilerin projelerini ve görevlerini tek yerde takip etmesi; hangi işin hangi aşamada olduğunun görsel (Kanban) ve sayısal (dashboard) olarak görülmesi.

## Çözdüğü sorunlar
- Görevlerin durumunun dağınık takibi
- Kimin neyle ilgilendiğinin belirsizliği (proje üyeliği + görev atama)
- Büyüyen görev listelerinde bulma güçlüğü (arama/filtre/sıralama)

## Kullanıcı deneyimi hedefleri
- Sürükle-bırak ile hızlı durum değişimi (iyimser UI güncellemesi)
- Dashboard'da tek bakışta özet
- Mobil, tablet ve masaüstünde sorunsuz kullanım

## Roller
ADMIN (tüm kullanıcı/proje yönetimi), USER (üyesi olduğu projeler; proje OWNER'ı üye yönetir).
